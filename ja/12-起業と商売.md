# 12. 起業と商売: 家財を賭けない

この節はお金と法的責任だけを計算し、寿命には換算しない。店を一つ・会社を一つ興す時に、どの段階で自分の金と家の金・配偶者の金まで一緒に壊れ得るか、法がどう定め、事前に防げるかを見る。経験だけで書き文献根拠のないものはC級とする。

### 1. 失ってもよい金だけで起業する。家財に手を出さず、借金して開業しない
<!-- 成本标签: 钱=0 时间=少 毅力=些 收益=大 口径=金钱 -->
- コスト: 金はかからない。始める前に自分で一つの数字を決める。この金を全部失っても、住宅ローンの返済・子育て・受診に影響がない水準だ。その数を超えたら投資しない。家族の金と借りた金はこの数字に入れない。難しいのは、商売が回り始めて見える時により入れずに踏みとどまることだ。
- ひとことで言うと: 個人事業主が負った借金は本人名義の金と財産で返す。家族一緒の商売と分別できなければ家全体の財産で返す。会社にしても安全ではない。会社が借金を返せない時、株主が出資するとした額のうち期限の来ていない出資金は債権者が早期納付を要求できる。だからいくら入れるかは「全部失ってもローン返済と受診は続く」で決める。
- 効果: 失うのは金が消えることで終わらない。(中国基準) 個体工商戸(個人事業主)の債務は一人で営んだものなら本人名義の財産で弁済し(民法典56条)、家族が一緒だったか誰の財産で営んだか分別できなければ家庭共同財産で弁済する。夫婦が両方署名した債務は共同債務になり、一方が事後同意したものも同じだ(民法典1064条)。一方が自分名義で借りても債権者が夫婦の共同生活・共同経営に使われたことを証明すれば一緒に返す。会社側にも一条項ある。株主が出資するとした金が認繳出資で会社が期限を過ぎた債務を弁済できないなら、納付期限の来ていない分を債権者が早期納付要求できる(新会社法54条)。
- 根拠等級: B
- 出典: (中国基準) 全国人民代表大会 (2020). 民法典(第56条・第1064条)。 <https://www.spp.gov.cn/spp/fl/202006/t20200602_463888.shtml> ; 全国人民代表大会常務委員会 (2023). 公司法(2023年改正、第47条・第54条)。 <https://www.gov.cn/yaowen/liebiao/202312/content_6923395.htm> ; (日本対応) 法務省(民法・会社法)、日本政策金融公庫(創業融資・代表者保証)、中小企業庁。 <https://www.moj.go.jp> ; <https://www.jfc.go.jp> ; <https://www.chusho.meti.go.jp>
- 備考: (日本対応) 個人事業主は無限責任(全財産で弁済)で、法人(株式会社・合同会社)でも「代表者の個人保証」を入れたら同じことになる。日本政策金融公庫・銀行の創業融資も「代表者保証」を求める場合が多く、「保証を外すには担保・他の保証」が必要になる。融資の前に「自分がいくらまで失えるか」を紙に書く。

### 2. 会社のローンに個人連帯保証の署名をしない。配偶者はなおさら別々に署名しない
<!-- 成本标签: 钱=0 时间=少 毅力=些 收益=大 口径=金钱 -->
- コスト: 金がかからない。銀行・仕入先・家主が「株主個人の連帯保証」や「配偶者の署名」を求めたらまず止まる。あの一枚に署名すると「会社の借金は個人に来ない」という保護(有限責任)を自ら手放すことになる。署名しなければしないで通し、やむを得ない時は「普通保証」だけにして保証限度額を明示する。難しいのは、相手がしばしば「署名しないと融資しない」と言う圧力に耐えることだ。
- ひとことで言うと: 「連帯責任保証」で署名すると、会社が金を返せない時に債権者が会社を飛ばして直接本人に来る。「普通保証」なら先に会社を訴え、会社財産を強制執行して足りない分だけ本人が補う。配偶者が一緒に署名すれば二人の財産が一緒に賭かり、有限責任会社の「有限」が個人には無効になる。
- 効果: 保証書のあの文の意味は「借金した人が返さなければ本人が返す」だ。連帯保証で書けば債権者が会社に行かず直接保証人に来る。普通保証なら債権者がまず会社を訴訟・仲裁し、会社財産の強制執行を申し立て、その金が足りない部分だけ保証人が補う。(中国基準) 夫婦が両方署名した債務は共同債務で、一方の事後同意も同じだ(民法典1064条)。配偶者が署名すれば二人の財産が一緒に賭かる。
- 根拠等級: A
- 出典: (中国基準) 全国人民代表大会 (2020). 民法典(第681条・第687条・第688条・第1064条)。 <https://www.spp.gov.cn/spp/fl/202006/t20200602_463888.shtml> ; (日本対応) 民法446条以下(保証)・452条(催告の抗弁)・453条(検索の抗弁)、同法465条の2以下(個人根保証)。e-Gov法令検索 <https://elaws.e-gov.go.jp> ; 中小企業庁「経営者保証に関するガイドライン」(2013年12月~)。 <https://www.chusho.meti.go.jp> ; 日本政策金融公庫。 <https://www.jfc.go.jp>
- 備考: (日本対応) 民法446条以下の保証・452条(催告の検索)、453条は普通保証人の権利だ。日本では「代表者個人保証」が融資の慣行だが、信用保証協会の「経営者保証ガイドライン(2013年~ — 一定条件で代表者保証を外した融資)」がある。署名の前に「この一枚に何を署名するか」を明確にする。保証金額は第1条の「耐えられる」数字の中に抑える。

### 3. 開業前に主体を正しく選ぶ。個人事業主と組合員は最後まで賠償し、有限会社だけが「有限」だ
<!-- 成本标签: 钱=少 时间=中 毅力=否 收益=大 口径=金钱 -->
- コスト: 金はほとんどかからないが、時間は取られる。登記は自治体のオンライン申請で数時間だ。法人にした後は毎月の記帳・申告が続く。自分でやれば時間、人に頼めば代行料がかかり、金額は地域と事務所で違う。難しいのは、記帳と申告を止めずに続けることだ。
- ひとことで言うと: 個人事業主と普通の組合員はいくら借りてもそのまま追い、有限会社の株主は設立時に出資するとした額だけ賠償する。ただし出資するとした分は期日までに実際に出す。100万円と書けば100万円を負担し得るという意味だ。会社の口座と家の口座を混ぜ、会社に借金を隠せば「有限」も無効になる。株主が一人なら口座が混ざっていないことを本人が証明しなければならない。
- 効果: 個人事業主が負った債務は、自分の金と物で返すか、家全体の金と物で返す。普通パートナーシップ企業(普通合伙)のパートナーは、企業の債務について無限連帯責任を負う。借りただけ返すという意味で、返し切れれば終わる話ではない。債権者はパートナーの一人だけを捕まえて全額を請求できる。有限パートナーシップ(有限合伙)は違う。中の有限パートナーは自分が約束した出資の額までしか賠償しない(認繳出資を限度)。有限責任会社の株主も同じく約束した出資の額までだ(認繳出資額を限度)。ただし「有限」は三つの場合に無効になる。①約束した金は会社成立から5年内に実際に納めなければならず、会社が期限の来た債務を返せない時は債権者が早期納付を要求できる。②すでに入れた金を引き出した場合(抽逃出資)は返さなければならない。③会社を殻にして債務を逃げ、債権者の利益を大きく害した場合、会社の債務を個人が連帯して負う。株主が一人の会社はさらに厳しい。株主自身が会社の金と自分の金が分かれていることを証明しなければならない。証明できなければ、会社の債務を個人が連帯して負う。裁判所は主に金と帳簿が分かれているかを見る。株主が会社の金を勝手に使い、記帳もしない、会社の帳簿と個人の帳簿が不分なら、すべて混同と数える(中国基準、2024年7月以降)。
- 根拠等級: B
- 出典: (中国基準) 全国人民代表大会 (2020). 民法典(第56条)。 <https://www.spp.gov.cn/spp/fl/202006/t20200602_463888.shtml> ; 全国人民代表大会常務委員会 (2006). パートナーシップ企業法(2006年改正、第2条)。 <http://www.gov.cn/gongbao/content/2006/content_413955.htm> ; 全国人民代表大会常務委員会 (2023). 公司法(2023年改正、第4条・第23条・第47条・第53条・第54条。第23条第3款「一つの株主のみの会社で、株主が会社財産が株主自身の財産から独立していることを証明できないときは、会社の債務について連帯責任を負わなければならない」)。 <https://www.gov.cn/yaowen/liebiao/202312/content_6923395.htm> ; 最高人民法院 (2019). 全国法院民商事審判工作会議紀要(第10点「人格混同」、「最も主要な表現は会社の財産と株主の財産が混同し区別できないことだ」「会社の帳簿と株主の帳簿が不分で、会社財産と株主財産が区別できない」)。 <https://www.court.gov.cn/zixun/xiangqing/199691.html> ; (日本対応) 会社法104条(株主の有限責任)・577条(持分会社の有限責任社員)、民法676条(パートナーシップ債務の連帯責任)。法務省。 <https://www.moj.go.jp> ; e-Gov法令検索 <https://elaws.e-gov.go.jp>
- 備考: (日本対応) 株式会社・合同会社の社員(株主・出資者)は出資を限度とする(会社法104条・577条)。個人事業主は無限責任、民法定義の組合は組合債務に対し持分2倍まで連帯責任を負う(民法676条)。会社資金と個人の資金を分け、客の代金を個人カードで受けず、会社の金で家計の支出をしない。帳簿を完全に残す。資本金を見栄えで大きく書かない。法人格の濫用(会社と個人の区別がつかない場合)では法人格否認で株主が直接責任を負い得る。

### 4. 名義株主にならず、他人の持ち分を代わりに保有しない
<!-- 成本标签: 钱=0 时间=少 毅力=否 收益=大 口径=金钱 -->
- コスト: 金はかからない。時間もほとんど取らない。「身分証を借りて株主に名を載せる」「株式はまず君の名義にしておく」と言われたら、すべて断る。難しいのは、断る理由を説明しなくてもよいと分かっていることだ。
- ひとことで言うと: 名前が登記簿に載っていれば法律上あなたが株主だ。設立時の出資金を期日までに納めなければならず、納めないと納付補充に会社の損害賠償まで負う。設立時に他の株主が実際に出資していなければ、不足分を一緒に埋めなければならない。商売は他人がして借金はあなたの名前で残る。
- 効果: 登記簿に載った株主は、法律上の株主だ。定款で定めた期限までに、約束した出資を一銭も欠かさず納めなければならない(認繳出資の足額納付)。期限までに納めない場合は、追納に加えて会社の損害も賠償する。会社設立時に他の株主が実際に金を納めていなければ、その不足分を設立時の他の株主が連帯して埋める。会社が期限の来た債務を返せない時は、債権者がまだ期限の来ていない分の早期納付を要求できる。実際に商売をしている人は登記に載っておらず、債務だけが自分の名義に残る(中国基準、2024年7月以降)。
- 根拠等級: B
- 出典: (中国基準) 全国人民代表大会常務委員会 (2023). 公司法(2023年改正、第47条・第49条・第50条・第54条)。 <https://www.gov.cn/yaowen/liebiao/202312/content_6923395.htm> ; 最高人民法院 (2020年修正). 会社法適用に関する若干問題の規定(三)(法釈〔2011〕3号、2014年法釈〔2014〕2号・2020年法釈〔2020〕18号で二度改正、第24条・第25条。「法律の定める無効事由がない場合、人民法院は当該契約を有効と認定すべきだ」「実際の出資者が会社の他の株主の半数以上の同意を得ずに株主の変更を請求する場合……人民法院は支持しない」「名義株主が持分を処分して実際の出資者に損害を与えた場合、実際の出資者の名義株主に対する賠償請求を人民法院は支持すべきだ」)。 <https://flk.npc.gov.cn/detail?id=ff808181799def980179ac07a9ca117c> ; 最高人民法院 (2025). 会社法適用に関する若干問題の解釈(意見募集稿)第90条。 <https://www.court.gov.cn/zixun/xiangqing/477881.html> ; (日本対応) 会社法340条(株主名簿の名義書換)・397条。法務省。 <https://www.moj.go.jp>
- 備考: (日本対応) 名義貸し・名義預かりの株主は「名義株主」として対外的に権利義務を負う。実質的課税では名義人でなく実質出資者に課税されるが、登記上の責任(出資義務・役員責任)は名義に残る。背任・横領リスクも本人に残る。他人の持ち分を預かる理由をよく考える。

### 5. フランチャイズ加盟の前に流通業・公正取引関連の登録を確認し、書面開示を受け取り、契約書に「解約猶予期間」を入れる
<!-- 成本标签: 钱=0 时间=中 毅力=否 收益=大 口径=金钱 -->
- コスト: 金はかからない。商務部の「商業特許経営情報管理システム」で、ブランド側に届出があるか調べる。次に、契約前に説明すべき事項を書面で渡すよう求め、契約書の草案と一緒に受け取る。数時間で終わる。
- ひとことで言うと: (中国基準) 規定上、ブランド側は先に直営店2店舗を1年以上運営し、契約後15日以内に商務部門に登録しなければならない。契約前に加盟金・保証金の返還方法・既存店舗の収支など12項目を書面でもらう。登録照会ができず、資料を出さず、金を払ってから契約書を見せる業者ならすぐ出る。
- 効果: 法規は、ブランド側(法規上は「フランチャイザー」＝加盟本部)に自分で開いて自分で経営する直営店が少なくとも2店、しかも1年以上の運営を求める。最初の加盟契約を結んだ日から15日以内に、商務主管部門へ届出をする。届出をしない場合は1万~5万元の罰金。期限を過ぎても届出をしない場合は5万~10万元の罰金で、さらに対外に公告される。契約前に、説明すべき事項を書面で渡さなければならず、全部で12項目だ。中には加盟金をどの種類でいくら取るか、保証金をどの場合に返すか、現在の加盟店数と商売の状況が入る。直近2年の監査済み会計報告の摘要、直近5年の訴訟と仲裁も入る。契約には、加盟店が契約後に一定期間内なら自分から一方的に解除できること(単方解除)も明記しなければならない。ブランド側が黙って言わない、または偽の情報を渡した場合、加盟店は契約を解除できる(中国基準、2007年5月以降)。
- 根拠等級: B
- 出典: (中国基準) 国務院 (2007). 商業特許経営管理条例(国務院令第485号、第7条・第8条・第12条・第22条・第23条・第25条)。 <https://www.gov.cn/zhengce/zhengceku/2008-03/28/content_4179.htm> ; 商務部 (2012). 商業特許経営情報披漏管理弁法(商務部令2012年第2号、第5条・第9条)。 <http://www.gov.cn/gongbao/content/2012/content_2177025.htm> ; 商務部 商業特許経営情報管理システム。 <https://txjy.syggs.mofcom.gov.cn/> ; (日本対応) 中小小売商業振興法(経済産業省)のチェーン加盟店契約の公正化、公正取引委員会の指定公正競争規約。 <https://www.meti.go.jp> ; <https://www.jftc.go.jp>
- 備考: (日本対応) 「中小小売商業振興法」の「チェーン加盟店契約の公正化(経済産業省・公正取引委員会の指定公正競争規約)」で、本部は契約の14日前までに「開示書面(運営費・売上高・店舗数・解約条件等)」を交付しなければならない。開示なし・登録なしで金を要求する業者は避ける。「クーリングオフ(中途解約 — 契約後一定期間の解約)」の条件も確認する。

### 6. 登記の前に屋号・営業所・業種・資本金を決めておく。書類が揃えばその場で登記証明書を受ける
<!-- 成本标签: 钱=0 时间=中 毅力=否 收益=中 口径=金钱 -->
- コスト: 登記そのものは無料だ。企業・個人事業主の登録登記料は2015年1月1日から徴収を停止している。自分で自治体のオンライン申請か窓口で行えば数時間で終わる。印鑑の作成、記帳の代行、登録住所の借用(住所托管)は市場で買うサービスであり、政府が取る費ではない。会社にした後は毎月の記帳・申告が続くので、そこに時間か代行料がかかる。
- ひとことで言うと: (中国基準) 登録自体は無料だ。登録手数料は2015年から徴収停止になり、金を要求されればそれは登録費ではない。提出書類は5つだけだ。申請書、身分または資格証明、営業所証明、定款または共同契約書、法規が別途要求するもの。書類が揃えばその場で許可証が発行され、その場発行ができなければ3営業日以内に処理し、複雑なものはさらに3営業日延びる。

### 7. 許認可が必要な業種は、許可が下りる前に開業しない

- ひとことで言うと: (中国基準) 無許可で開業すれば、その許可を所管する省庁が自らの法規で調査・処罰する。営業許可証すらなく別の罰則がなければ、業務停止命令と所得金没収に1万元以下の罰金だ。専売・専営品目を売ったり、証券・先物・保険・決済をしたりして情状が重ければ、違法経営罪で最下等級でも5年以下だ。
- 効果: 許可を取らずに開業した場合、その許可を所管する法律の指定部門が調査・処罰する。営業許可証すらなく、法律が罰則を定めていない場合は、営業停止を命じ、稼いだ金(違法所得)を没収し、さらに1万元以下の罰金を科す。さらに重い等級がある。法規が定める専売・専営または制限売買の物品を、許可なく経営する。証券・先物・保険・資金決済の四類の商売を、批准なく行う。この二つの情形で情状が重ければ違法経営罪を構成する。5年以下の有期懲役または拘役(短期の身柄拘束)に処し、稼いだ金の1倍~5倍を罰金として科す。情状が特に重ければ5年以上に処する(中国基準)。

### 8. 食品商売は、まず自分がどの等級に当たるか見る。製造と飲食は許可、小包装販売のみは届出、魚と野菜の販売は無許可で可能
<!-- 成本标签: 钱=少 时间=中 毅力=否 收益=中 口径=自由 -->
- コスト: 許可証そのものは無料だ。ただし場所と設備が基準を満たす必要があり、現場確認と許可取得に数週間かかる。肉を売るなら、各ロットの検疫証明と肉品品質検査合格証を残す。
- ひとことで言うと: (中国基準) 自分で作って売れば(粉食・煮物・ベーカリー・家で漬けた漬物)すべて許可が要り、小規模作業場と屋台は省の規則による。他人が作った完全包装食品だけを売るなら、許可なしで県級以上の市場監督部門に届ければよい。魚と生野菜の販売には資格証が不要だ。無許可なら商品価値が1万元未満でも5万~10万元の罰金だ。
- 効果: 食品安全法は、食品の商売にはまず許可が要ると定める。自分で食品を作り、食品を売り、飲食を営む場合は、すべて法により許可を取る。「ただし、食用農産物の販売と予包装食品のみの販売は、許可を取得する必要がない。予包装食品のみを販売する場合は、所在地の県級以上の地方人民政府食品安全監督管理部門に届け出る」。食用農産物とは生鮮肉・野菜のような未加工のもの、予包装食品とは他人が作り包装ごと売るものだ。「食品生産加工小作業場と食品屋台などの具体的な管理办法は省・自治区・直轄市が制定する」、この二類は各省が自ら規則を作る。許可を取らずに食品の商売をした場合、稼いだ金・食品・道具設備・原料をすべて没収する。この貨物を販売価格で計算した総額(貨値金額)が1万元未満なら、さらに5万~10万元の罰金を科す。貨値金額が1万元以上なら、貨値の10倍~20倍を罰金として科す。生豚屠宰管理条例は、豚は国の指定屠宰場でのみ屠り、官方が集中検疫すると定める。「農村地区の個人による自屠・自食は定点屠宰を実行しない場合を除き、いかなる単位・個人も定点を経ずに生豚屠宰活動をしてはならない」。「生豚製品の販売、肉食品の生産加工を行う単位・個人、および飲食サービス経営者・集中用餐単位が生産経営する生豚製品は、必ず生豚定点屠宰場(場)が検疫と肉品品質検査に合格した生豚製品でなければならない」。だから売る豚肉・使う豚肉はすべて指定屠宰場から来て、検疫と肉品品質検査の二関を通過しなければならない。指定屠宰場以外で勝手に豚を屠った場合、閉鎖を命じ、豚・屠宰の道具設備・稼いだ金を一緒に没収する。罰金の額は上の無許可食品と同じ等級だ。動物防疫法は、売る・運ぶ動物製品に検疫証明と検疫標識を添付することを求める。添付しなければ是正を命じ、同類合格貨の貨値金額の1倍以下を罰金として科す。司法解釈が扱うのは懲罰的賠償、つまり代金を返した上でさらに払う分だ。小作業場・食品屋台が作る・売る食品が食品安全基準に合わなければ、買い手が10倍賠償を求めた場合、裁判所は支持すべきだ(中国基準)。

### 9. 包装して売れば小包装食品だ。表示に製造日・消費期限・原材料名を一つも落とさず書く

### 10. 一般食品は病気を治すと言わない。ラベル・説明書・広告・ライブ配信のコメントもすべて含む
<!-- 成本标签: 钱=0 时间=少 毅力=些 收益=中 口径=自由 -->
- コスト: 金はかからない。宣伝文、商品詳細ページ、ライブ配信の話術を一度通しで見直す。難しいのは「血圧を下げる」「便秘を治す」のような言葉を飲み込むことだ。
- ひとことで言うと: 一般食品のラベル・説明書・広告は「病気を治す・防ぐ」と言えない。医療・医薬品・医療機器の3分類の広告だけが治療効果を語れ、他の広告は治療効果を語れず、薬のように聞こえる単語も使えない。罰金は広告費の1~3倍で、広告費の算定ができなければ10万~20万元だ(中国基準)。
- 効果: 食品安全法は「食品および食品添加物のラベル・説明書は、虚偽の内容を含んではならず、疾病の予防・治療機能に関わってはならない。生産経営者は提供するラベル・説明書の内容に責任を負う」と定める。「食品広告の内容は真実かつ適法でなければならず、虚偽の内容を含んではならず、疾病の予防・治療機能に関わってはならない。食品の生産経営者は食品広告内容の真実性・適法性に責任を負う」。つまり包装・説明書・広告のいずれでも自分が病気を防ぎ治せると言えず、書いたことの責任は売り手が負う。広告で食品を吹いて消費者を騙した場合は広告法で罰する。広告法にも禁令がある。「医療・医薬品・医療機器の広告を除き、他のいかなる広告も疾病治療機能に関わってはならず、医療用語または販売商品を医薬品・医療機器と混同させやすい用語を用いてはならない」。医療・医薬品・医療機器の三類の広告以外は、一律に治せると言えず、薬や医療機器に聞こえる言葉も使えない。この条に違反した場合、広告を止めさせる。さらに広告を出した側(広告主)に、出した範囲で公開で釈明し影響を消させる。その上で広告費用の1倍~3倍を罰金として科す。広告費用が算定できない、または明らかに低く申告した場合は10万~20万元の罰金を科す。情状が重ければ広告費用の3倍~5倍、または20万~100万元の罰金を科す。営業許可証を取り消すこともでき、商売そのものができなくなる(中国基準)。

### 11. 食品業界には刑事的な赤線がある。病肉と基準超過品を売ればすでに罪になり、有毒有害物質を混ぜれば金額を見ずに5年以下から始まる
<!-- 成本标签: 钱=0 时间=少 毅力=否 收益=大 口径=自由 -->
- コスト: 金はかからない。第8条(食品商売で自分がどの等級かを見る)のやり方を通す。検疫証明と仕入れ証憑を残し、原材料表には承認番号が確認できるものだけを入れる。
- ひとことで言うと: 前の条項が金を稼ぐことなら、この条項は人を捕まえる。病死家畜の肉・検査不合格肉・農薬・動物用医薬品・重金属が著しく基準を超えた品を売れば3年以下だ。人が重い中毒を起こす「程度」だけで既に罪になり、実際に被害者が出たかは要らない。食品に有毒有害な非食品原料を混ぜれば、売上額を見ずに5年以下から始まる(中国刑法基準)。
- 効果: 刑法143条が扱うのはこの等級だ。自分が作る・売る食品が食品安全基準に合わない場合、「重い食品中毒事故その他の重い食源性疾病を引き起こすに足る」だけで既に罪になる。3年以下の有期懲役または拘役(短期の身柄拘束)に処し、同時に罰金を科す。人の健康に重い損害を与えた、またはその他の重い情状があれば、3年以上7年以下に処し罰金を科す。結果が特に重ければ、7年以上の有期懲役から無期まで、罰金または名下の財産の全部没収に処す。144条が扱うのは混入だ。作る・売る食品に有毒有害な非食品原料を混ぜた、または混ぜたと知って売った場合、5年以下の有期懲役に処し罰金を科す。人の健康に重い損害を与えた、またはその他の重い情状があれば、5年以上10年以下に処し罰金を科す。人を食べさせて死なせた、またはその他の特に重い情状があれば、141条で処罰する(10年以上・無期または死刑)。最高人民法院と最高人民検察院は一つの解釈(両高解釈)を出している。どの情形が「重い食品中毒事故その他の重い食源性疾病を引き起こすに足る」に当たるかを列記した。①「基準限量を重く超える病原性微生物・農薬残留・獣薬残留・生物毒素・重金属等の汚染物質を含む」。②「病死・死因不明または検疫検査不合格の畜・禽・獣・水産動物の肉およびその製品に属する」。③「国が疾病防控等の特殊な必要のために明令で生産・販売を禁止したものに属する」。④「特殊医学用途処方食品、乳幼児専用の主食・補助食品の栄養成分が食品安全基準に重く合致しない」。添加物を過量に使い、使う場所を誤り、上述の結果を生む程度に至れば、同じく143条で定罪する。「有毒・有害な非食品原料」とは何かは自分では決められない。一类は法律法規が食品に入れることを禁じた物質。もう一类は国務院の関係部門が公告した名单上の物質で、たとえば禁用農薬、食用動物に使うことを禁じた薬だ。もう一つの情形も144条の「その他の重い情状」に数える。10万~20万元未満を作った・売った。場所が小中学校の校内・幼保施設・養老施設およびその周辺。売る相手が未成年者・高齢者。指定屠宰場以外で自分で豚の屠宰場を設けて屠宰・販売し、情状が重ければ違法経営罪で処罰する。10万元以上に達した、または5万元以上を稼いだ場合が「情状が重い」に当たる(中国基準)。

### 12. 許可証を受けたら申告義務が始まる。収入がなくても期限内にゼロ申告(すべての欄が0の申告書)をする

- コスト: 金はかからない。自分でe-Tax(電子申告)で月次または四半期に申告すれば、一回数分だ。記帳を人に頼めば市場での別の出費になる。人を雇った場合は、成立の日から30日以内に社会保険の登記もする。難しいのは、商売のない月も期限を忘れずに申告することだ。
- ひとことで言うと: 許可証を受ければ期限内に税務申告する。一文も稼げなくても申告書の数字をすべて0にして提出する。未申告は期限内是正命令の対象で2,000元以下の罰金が可能で、情状が重ければ2千~1万元だ(中国基準)。3種の税を3か月連続で申告しなければ、システムが自動的に非正常口座に分類し、税務発行が止まる。
- 効果: 「納税者は納税期内に納付すべき税額がない場合も、規定に従い納税申告をしなければならない」。この期に一銭も税を払わなくても、申告書は出す。「期限どおりに申告しない場合、税務機関が期限を定めて是正を命じ、2000元以下の罰金を科すことができ、情状が重ければ2000元以上1万元以下の罰金を科すことができる」。申告せず税も少なく納めた場合、税を追徴し、日割りで加算する滞納金も一緒に納めさせ、さらに少納した税額の「50%以上5倍以下」の罰金を科す。滞納金は1日万分の5で加算する。「すべての税種について3か月連続で納税申告をしなかった場合、税収徴管システムが自動的に非正常状態と認定し、その発票領用簿と発票の使用を停止する」。3か月何も申告しなければ、システムが自分で非正常状態に分類し、発票を受け取ることも発行することもできなくなる。追申告して処罰を受けた後、自動的に解除される。人を雇った単位は「成立の日から30日以内に……所在地の社会保険経営機構に社会保険登記を申請しなければならない」(中国基準)。

### 13. 税務請求書は実際の取引だけを発行する。小規模納税者は免税枠を十分使う
<!-- 成本标签: 钱=0 时间=少 毅力=否 收益=大 口径=自由 -->
- コスト: 金はかからない。発票を買わず、売らず、他人のために「口座を通して発票を切る」こともしない。実際に起きた取引どおりに発票を切り、申告する。
- ひとことで言うと: (中国基準) 小規模納税者は2027年末まで、月商10万元・四半期売上30万元を超えなければ増値税が免除され、本来3%のものも同時期1%に下がる。逆に、他人の税務請求書を発行してもらい控除すれば偽装発行で、最下3年以下に2万~20万元の罰金だ。
- 効果: 規模が小さく簡易な方法で納税する等級を小規模納税者という。法律の文言は「販売額が課税最低限(起徴点)に達しない場合、増値税を免除する」。この線を起徴点(課税最低限)という。2026年1月1日から2027年12月31日まで、起徴点は月で10万元、四半期で30万元だ。回または日で計算する場合は1000元で、この線に売上が届かなければ納めなくてよい。同じ期間、本来3%で納めるものが1%に下がる。住宅・店舗の賃貸と土地使用権の譲渡は除く。逆に、実際の売買のない増値税専用発票、またはその他控除に使える発票を切れば、それは虚開だ。3年以下の有期懲役または拘役に処し、2万~20万元の罰金を科す。他人に切る、自分に切る、他人に自分宛てに切らせる、他人に切るのを紹介する、いずれも数える。かかわる税額が大きければ3年~10年。金額が巨大なら10年以上または無期に処する(中国基準)。

### 14. 税務署を装って電話やメッセージで指定口座に税金を納めさせるのはすべて詐欺だ。税務はe-Taxと税務署窓口だけで行う

- ひとことで言うと: (中国基準) 税務部門は電話で銀行カードの暗証番号・決済暗証・SMS認証番号を要求せず、税金を送る口座も教えない。実際に口座調査に来る人は検査通知書と検査証を提示する。この種の電話が来たらまず切り、12366で確認する。すでに振り込んだら直ちに110または96110で支払停止を求める。

### 15. 金を受け取る時は「手付金(手付け)」と書き、「予約金」と書かない。違約金は数値を明示し、掛売りは融資審査のように見る
<!-- 成本标签: 钱=0 时间=少 毅力=否 收益=大 口径=金钱 -->
- コスト: 金はかからない。契約に「手付金(定金)」の二文字を書き、金額を契約総額の20%以内に抑える。先に金を受け取ってから品を送る。相手に先に品を渡し後で払う(掛売り・サイト)と約束する前に、相手を一通り調べる。
- ひとことで言うと: 「手付金(手付け)」の二文字ならば倍額規則が付く。本人が契約を破ればこの金を返してもらえず、相手が破れば2倍で返す。契約額の20%を超える部分は認められない(中国基準)。「予約金」と書けばこの規則がない。掛売りは自分の金を無償で貸すことで、相手が潰れれば貸倒れになる。
- 効果: 手付は実際に相手の手に金が渡って初めて成立する(実際交付の時に成立)。手付を払った側が契約を破れば、この金は戻らない。手付を受け取った側が破れば、元の額を返し、さらに同じ額を上乗せして返す(倍額返還)。契約総額(主契約の目的額)の20%を超える部分は手付として数えない。約束した違約金が実際の損害より極端に高い、または極端に低い場合、裁判所は一方の請求により下げることも上げることもできる。違約金と手付の両方を契約に書いた場合、実際に違反が出ればどちらか一方しか取れず、両方は取れない(中国基準、2021年以降)。
- 根拠等級: A
- 出典: (中国基準) 全国人民代表大会 (2020). 民法典(第585条・第586条・第587条・第588条)。 <https://www.spp.gov.cn/spp/fl/202006/t20200602_463888.shtml> ; (日本対応) 民法557条(手付 — 解約手付の推定、手付の放棄または倍額償還による解除)。法務省。 <https://www.moj.go.jp> ; e-Gov法令検索 <https://elaws.e-gov.go.jp>
- 備考: (日本対応) 民法557条の「手付(違約手付 — 解約手付の推定)」は「手付を放棄または倍返しで契約を解除できる」ルールだ(当事者間の特約で変更可)。「手付金・内金・予約金」の区別は契約書の定義条項で明確にする。掛売りは与信管理(与信限度・回収条件)を先に決める。

### 16. 人を雇ったら最初の1か月以内に書面契約を書き、14日以内に社会保険の取得届出をする
<!-- 成本标签: 钱=多 时间=少 毅力=否 收益=大 口径=金钱 -->
- コスト: 社会保険のうち会社が負担する部分は、ずっと払い続けなければならない。率は地域で違う。契約書そのものは金がかからず、所轄の労働部門のモデル契約をそのまま使えばよい。難しいのは、人を雇った瞬間からこの固定費が始まることを受け入れることだ。
- ひとことで言うと: (中国基準) 出勤して1か月経っても書面契約がなければ、2か月目から毎月賃金の2倍を支払い、1年を満たすまで計算する。社会保険は就業開始30日以内に登録し、しなければ納付すべき保険料の1~3倍の罰金だ。法に「従業員が自ら社会保険を放棄する」という項目はない。
- 効果: 人が出勤して1か月を過ぎ、1年に満たないうちに書面契約がなければ、毎月賃金の2倍を支払わなければならない。人が働き始めた初日から30日以内に社会保険の登記をする。しなければまず是正を命じる。期限を過ぎたら納付すべき社会保険料の1倍~3倍を罰し、この件を扱う人にさらに500元~3000元を罰する。社会保険を期限どおりに納めず、または全額納めなかった場合、欠いた日から1日万分の5で加算する(滞納金)。期限を過ぎても納めなければ、さらに欠款の1倍~3倍を罰する。単位は自ら申告し、期限どおりに全額を納めなければならない。天災のような抗えない法定事由がある場合に限り、遅納または少納ができる。「従業員が自ら放棄する」という項目はない(中国基準)。

### 17. 賃金は契約と法どおりに払う。昇給・貸付・賞与はすべて書面にする
<!-- 成本标签: 钱=0 时间=少 毅力=些 收益=中 口径=金钱 -->
- コスト: 金はかからない。契約に賃金をはっきり書く。昇給・賞与・立替・貸付は、すべて署名して紙を一枚残す。口頭で約束しない。自分のポケットから会社の代わりに賃金を出すこともしない。難しいのは、顔見知りが口を開いた時にもこの規律を通すことだ。
- ひとことで言うと: 賃金は契約と法どおりに期限内に全額支払う。滞れば従業員が直ちに労働基準監督署に申告できる。賃上げ・賞与・貸付を口約束にすれば、争いの時に証拠を出せない側が損をする。社長が従業員にお金を貸すのは法律が書面を強制しないが、借用書を書き金額・利息・返済時期を書く方がよい。
- 効果: 労働契約に必ず書く内容には、賃金の払い方と社会保険の納め方が含まれる。単位は契約と国の規定に従い、遅滞なく全額の賃金を支払わなければならない。滞れば、従業員は直接裁判所に支払督促(裁判所の発する催告文書)を申請できる。社長が自分の金を従業員に貸すのは、それ自体が金銭消費貸借契約だ。民法典の原文は「借款契約は書面の形式を採用すべきである。ただし、自然人相互の借款に別段の約定がある場合はこの限りでない」。社長個人が従業員に貸すのは、ちょうど二人の自然人の間の借り貸しで、法律は書面を強制しない。契約内容は「一般に借款の種類・通貨・用途・金額・利率・期限・返済方法などの条項を含む」。この項目に沿って借用書を一通書くのは著者の提案だ。口頭で約束した賞与は白紙黒字がなく、実際に争えば証拠を出せない側が損をする(中国基準)。

### 18. 先に売って後に作る。予約販売と小口注文で買う人がいるか確認してから製造に金を入れる
<!-- 成本标签: 钱=少 时间=中 毅力=些 收益=大 口径=金钱 -->
- コスト: 数十~数百円で、見本かページを一つ作る。次に実際の客を数十人探し、前払いさせるか小口注文を出させる。その分、直接製造を始めるより数週間遅れる。難しいのは、先に品を作り出さないことを堪えることだ。
- ひとことで言うと: イタリアの研究が発見した。先に仮説を立て、市場反応で検証する起業者の方が商売がうまくいった。彼らは方向を適時に変え、早く諦めもした。前払いしてくれる人がおらず小口注文もなければ「作れば勝手に買ってくれる」を信じない。
- 効果: 無作為化比較試験が一つあり、イタリアの新興企業116社を約1年追跡した。無作為化比較試験とは、人を無作為に二群に分け、片方の群にだけ研修を行い、両群の結果を比べるものだ。結果はこうだ。研修を受け、「先に仮説を立て、市場の反応で厳格に検証する」という仕方で意思決定する起業家は、業績がより良かった。彼らは方向を適時に変える確率も高く、早期に諦める割合は高くなかった。見た目は有望だが実際には成し遂げられない計画を、著者らは偽陽性計画と呼ぶ。著者らの解釈は、このやり方がそうした計画に金を注ぎ続ける確率を下げたというものだ(イタリア、2020年発表)。
- 根拠等級: B
- 出典: Camuffo A, Cordova A, Gambardella A, Spina C (2020). A Scientific Approach to Entrepreneurial Decision Making: Evidence from a Randomized Control Trial. Management Science 66(2):564-586. <https://doi.org/10.1287/mnsc.2018.3249> ; (日本対応) 中小企業庁(創業支援・事業承継)、日本政策金融公庫(新規開業資金)。 <https://www.chusho.meti.go.jp> ; <https://www.jfc.go.jp>

### 19. 試作品ができたら量産チェックリストで先に点検してから稼働を論じる
<!-- 成本标签: 钱=少 时间=中 毅力=些 收益=大 口径=金钱 -->
- コスト: 数百~数千円で小ロットの試作を一度行う。さらに数時間かけて良率を計算する。100個のうち何個が売れるかだ。仕入先の最小発注量と支払期限、在庫がいくら金を占めるか、包装と物流、認証と許可、商標も、一つずつ計算する。難しいのは、この段階を飛ばして直接着工しないことを堪えることだ。
- ひとことで言うと: 試作品1個と1,000個の違いは、金がどこで潰れるかにある。歩留まりが本当の原価を決め、最小発注量と支払期限がいくら先に必要かを決め、在庫が金がいつ戻るかを決める。製品が義務認証の対象なら、認証なしに認証表示を付けられず出荷・販売もできない。
- 効果: 見本1個と1,000個の違いは、金がどこに寝ているかにある。良率が真の原価を決める。良率とは、作った一ロットのうち何割が合格して売れるかだ。仕入先が一度に最低どれだけ注文させるか(最小発注量)、出荷後いつ金を受け取れるか(支払期限)の二つが、先にいくら立て替えるかを決める。在庫が金の戻る時期を決める。強制製品認証目録に載る製品は、まず認証を通し、製品に認証マークを表示して初めて出荷・販売できる。認証なしに勝手に出荷・販売すれば、認証認可条例で処罰する。飲食と食品販売には食品営業許可が要る(中国基準)。

### 20. 仕入れの時、領収書と仕入先情報を一組ずつ残し、仕入値が市場より明らかに安い品は受け取らない。従業員が会社のために調達した偽物も会社の犯罪として数えられ、社長が刑を受ける人だ
<!-- 成本标签: 钱=0 时间=少 毅力=些 收益=大 口径=自由 -->
- コスト: 金はかからない。ロットごとに次のものを残す。仕入契約書、発票、支払記録、仕入先の営業許可証と授権書類。さらに内部の規律を一つ決める。仕入れた者が署名し、市場価格より明らかに安いものは一律に入れない。難しいのは、よく儲かりそうに見える安値品を手放すことだ。
- ひとことで言うと: 偽物を売って3万元稼ぐか5万元売れば既に刑の対象で3年以下だ(中国刑法基準)。売れ残りの在庫も価値が販売基準の3倍に達すれば計算に入る。「知らずに売った」は本人の言葉では通らない。仕入値が市場より明らかに安いのに理由を言えなければ、知っていたと認められる。仕入契約書・税務請求書・支払記録・仕入先情報を残せば免責の道が開ける。

### 21. 商品・包装・タグ・宣伝図案の意匠は自分で作るかライセンスを買う。色を変えアイコンを一つ付けるのは「直した」ではない

### 22. 職務では規定どおりに働く。規定外の好意は、まず責任が誰に帰するか考える

### 23. 赤字なら手順どおりに出る。簡易抹消が可能なら抹消し、資本が借金を覆えなければ破産し、放置しない
<!-- 成本标签: 钱=0 时间=中 毅力=些 收益=大 口径=金钱 -->
- コスト: 簡易抹消は自分でできる。国家企業信用情報公示システムに20日間掲示する。まだ返し終えていない債務があれば、まず帳簿を整理し、受け取るべきは回収し、返すべきは返す。この段階を清算という。破産は裁判所に申し立て、数か月かかる。難しいのは、赤字になって向き合いたくない気持ちを押さえ、先送りしないことだ。
- ひとことで言うと: (中国基準) 借金・賃金・税金・保険料がなければ、全出資者が約束文書を書き、20日の公告に異議がなければ簡易抹消になる。個体工商戸は公告なしで10日異議がなければ即時抹消だ。会社が借金を返せなければ破産を申請できる。放置して2年間 年次報告をせず連絡も取れなければ許可証が取り消され、責任ある法人代表は3年間再び法人代表になれない。

### 24. 代行運営業者に金を払いネット店舗を任せる・開業教育を受ける・「在庫なし販売」をする前に、後でさらに金を払う必要があるか、販売数がどこから来るかをまず聞く
<!-- 成本标签: 钱=0 时间=少 毅力=些 收益=大 口径=金钱 -->
- コスト: 金はかからない。金を払う前に三つを取りそろえる。書面の契約、相手会社の正式名称、返金の条件。金は契約に載ったその会社にだけ払い、個人の口座には振らない。難しいのは、相手が「受講生は月収一万を超えた」という画面を見せてきた時、その場で払わないことを堪えることだ。
- ひとことで言うと: この種の詐欺は、まず一度金を受け取り、「アップグレードパッケージ」・代金の前払い・凍結解除金でさらに払わせる。管理画面の注文と収益は作られたもので、出金しようとした瞬間に止まる。偽レビューで販売数を上げること自体が違法で、摘発された代行業者は処罰される。

- 効果: 民法典279条は「业主が住宅を経営性用房に変更する場合、法律・法規および管理規約を守るほか、利害関係を有する业主の一致した同意を得なければならない」と定める。最高人民法院の司法解釈はもっと細かい。同じ棟の他の业主はすべて「利害関係を有する业主」に数える。同じ団地の別棟の业主は、自分の家の価値または生活の質が影響を受けたことを証明して初めて数える。彼らの一致した同意なく変更した場合、中止・原状回復または損害賠償を請求されれば、裁判所は支持すべきだ。「多数の业主が同意した」という弁解は、裁判所は支持しない。生態環境法典は2026年8月15日から施行し、大気汚染防止法は同時に廃止される。法典250条は三類の場所での煙・異臭・排気を生む飲食サービス項目の新設・改設・拡設を禁じる。①居住住宅楼。②専用排煙ダクトを備えない商住総合楼。③商住総合楼のうち住戸階と隣接する商業階。違反した場合、まず是正を命じる。拒んで改めなければ閉鎖を命じ、1万~10万元の罰金を科す。法典はまた、地方政府に登記登録の段階で飲食店の立地に関する禁止的要件を提示することを求める。食品営業許可を申請する際、場所は経営する食品の品種・数量に適合し、有毒有害な場所やその他の汚染源と規定の距離を保たなければならない。逆に、建物自体が法律・行政法規の使用条件に関する強制規定に合わず、使えないのが自分のせいでなければ、賃貸契約を解除できる(中国基準)。
- 根拠等級: B

### 28. 大勢で店を興すなら、開業前に出資・分配・決定権・給与・退出方法を書面契約に書く
<!-- 成本标签: 钱=0 时间=中 毅力=些 收益=中 口径=金钱 -->
- コスト: 金はかからない。何人かのパートナーが一、二回座って話し、十数項目をはっきり書いて、各自が署名する。ネットにパートナーシップ契約の雛形があり、パートナーシップ企業法が挙げる十項目を順に埋めればよい。難しいのは、顔見知り同士で「金の話は情を傷つける」と感じ、口を開きにくいことだ。
- ひとことで言うと: 契約書に5つを書く。各自がいくら入れるか、利益をどう分けるか、誰が最終決定をするか、参加者に給与を払うか、辞めたい時に持ち分をどう整理するか。この5項目が紙になければ、商売がうまくいくたびに争いが生まれる。
- 効果: パートナーシップ企業法4条は、パートナーシップ契約を全体のパートナーの協議一致により書面の形式で締結すると明記する。18条は契約に書く十項目を列記した。出資の方式・金額・納付期限、利益分配・損失分担の方式、パートナーシップ事務の執行者が誰かが入る。さらに入伙と退伙、争議の解決方法、解散と清算、違約責任も入る。パートナーシップ企業を設けず、数人がただ組んでやる場合は民法典のパートナーシップ契約が適用される。契約に書かなければ、民法典にいくつかの既定ルールがある。パートナーシップの事柄を決めるには、契約に別段の定めがなければ全体のパートナーの一致した同意が要る。パートナーシップ事務を執行するパートナーは、そのために報酬を要求できない。契約に別段の定めがある場合を除く。利益と損失は契約の約定で分ける。約定がなければまず協議する。協議が調わなければ、実際に納めた出資の割合で分ける。割合も計算できなければ均等に分ける。パートナーはパートナーシップの債務について連帯責任を負い、多く返した者は他の者に求償できる。パートナーシップの期限を定めていなければ不定期パートナーシップとし、パートナーはいつでも解除できる。ただし他の者に相当な期間を置いて通知する。パートナーシップ企業を設けた場合、期限を定めていなければ、パートナーは30日前に他の者に通知すれば退伙できる。契約で利益の全部を一部の者だけに分け、または一部の者に損失の全部を負わせる約定はできない(中国基準)。
- 根拠等級: B
