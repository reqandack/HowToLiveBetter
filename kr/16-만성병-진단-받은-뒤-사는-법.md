# 16. 만성병 진단을 받은 뒤 사는 법

### 2. 외래 만성특수질환 인정을 먼저 받고 다른 지역 진료 신고를 받아 고혈압, 당뇨, 항암 방사선치료, 투석, 이식 후 거부반응 약을 다른 지역에서 바로 정산한다
<!-- 成本标签: 钱=0 时间=少 毅力=否 收益=大 口径=金钱 -->

### 3. 재검은 의사가 준 간격대로 하고 매번의 지표를 같은 노트에 적는다

- 근거등급: B
- 비고: 「가정 혈압 측정 + 기록」은 「치료 조정」의 근거다. 「검사 결과 상호 인정」(「의료기관 간 검사결과 공유 — 건강정보 서비스(마이헬스웨이)」)도 본다(세부 확인 필요).

### 4. 민간요법과 건강기능식품을 시험하려고 정식 치료를 멈추지 않는다

### 5. 상태가 안정된 만성병은 동네 병원에서 한 번에 12주 분의 약을 받을 수 있다
