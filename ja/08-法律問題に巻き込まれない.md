# 8. 法律問題に巻き込まれない

### 1. 交通事故を起こしたら停止して人を救護し通報する。逃げない
<!-- 成本标签: 钱=0 时间=少 毅力=否 收益=大 口径=自由 -->
- コスト: 金がかからない。停止、ハザードランプ、救護、通報後の交通警察待ちは最大1~2時間だ。軽い事故で負傷者がおらず双方が事実について争いがなければ、まず写真を撮る。相手の氏名、電話、車両番号、免許番号、保険証券番号、衝突部位を記録する。双方が署名すれば現場を先に離れ、後で別途協議してもよい。
- ひとことで言うと: 逃げればこの事故はあなたの全責任で基本処理される。免許は取り消され、生涯再試験を受けられない。(中国基準) より現実的な層: 車両損害保険と対物賠償責任保険は逃走に一切賠償しないので、数十万元の賠償をすべて自分で払う。現場に残って救護し通報すれば最大1~2時間だ。
- 効果: (中国基準) 逃げた側がこの事故の全部責任を負う。相手にも過失があったとあなたが証明できる時だけ責任が少し減り得る。逃走すれば運転免許も取り消され、生涯の再取得が不可能だ。この事故が交通肇事罪を構成すれば、逃走で3~7年。逃走で人が死ねば7年以上。保険も扱わない。商業車両保険の車両損害と対物賠償責任保険は「交通事故逃走」「故意の現場破壊・偽造・証拠隠滅」に遭うと一切賠償しないので、数十万元の賠償を自費で全額支払う(中国基準)。
- 根拠等級: A
- 出典: (中国基準) 全人代常務委員会 (2021). 中国道路交通安全法(2021改正、第70・101条). <https://jtgl.beijing.gov.cn/jgj/jgxx/flfg/fl/205308/index.html>(北京市公安交通管理局転載) ; 中国国務院 (2017). 中国道路交通安全法実施条例(国務院令第405号、2017改正、第86・92条). <http://xzfg.moj.gov.cn/front/law/detail?LawID=75> ; 全人代 (1997). 中国刑法(第133条). <https://www.spp.gov.cn/spp/fl/201802/t20180206_364975.shtml> ; 中国保険業協会 (2020). 自動車商業保険標準条款(2020版、第9・22条). <https://www.iachina.cn/art/2020/9/4/art_24_104621.html>
- 備考: 負傷者がいればまず救護し、次に通報する。救護のために現場を動かさなければならないなら、車と人の元の位置をまずマークする。「軽くぶつかったが感覚がなくそのまま走り去った」も事後に逃走と計算され得る。確信がなければ通報する。保険条款は標準条款を引用したもので保険業界の統一テンプレートなので、実際に何を賠償できるかは自分の保険約款が優先する。(日本対応) 日本ではひき逃げ(救護義務違反)は道路交通法72条違反で5年以下の懲役または50万円以下の罰金、死亡ひき逃げでは自動車運転致死傷罪(自動車の運転により人を死傷させる行為等の処罰に関する法律)や危険運転致死傷罪、保護責任者遺棄罪が問われ得る(警察庁の公式基準で確認)。現場に残って救護・通報する義務は同じだ。

### 2. 詐欺に遭ったことに気づいたら直ちに110番または金融機関に支払停止を求める。まず自分で調べない
<!-- 成本标签: 钱=0 时间=少 毅力=否 收益=大 口径=金钱 -->
- コスト: 金がかからない。電話1本で振込時刻、金額、相手口座を伝える。振込画面のキャプチャとチャット記録をしっかり残す。
- ひとことで言うと: 送金された直後の短い時間が最も重要だ。警察が緊急の支払停止・迅速凍結をでき、銀行は必ず協力しなければならない。金が移動・分散された後は回収確率が大きく下がる。だからまず110番(または消費者ホットライン188)にかけ、自分で調査・問い合わせから始めない。詐欺の疑いで金融機関の窓口や警察からかかってくる電話はあなたを止めようとするものなので必ず出る。
- 効果: (中国基準) 公安機関は事件関連資金に即時照会、緊急支払停止、迅速凍結をする権限がある。銀行と支払機関は必ず協力しなければならない。凍結された金は手続きに従って被害者に返還される。金が移動・分散すれば回収確率が大きく下がるので、支払停止が早いほど効果的だ。96110は全国統一の反詐欺予報・防止ホットラインで、かかってくる電話は警察があなたを止めようとするものなので必ず出る(中国基準、2022年12月から)。
- 根拠等級: A
- 出典: (中国基準) 全人代常務委員会 (2022). 中国反電信網絡詐欺法(第20・34条). <https://www.spp.gov.cn/spp/fl/202209/t20220902_575631.shtml> ; 福建省公安庁(中国基準) (2023). 96110電話は必ず出ろ. <http://gat.fujian.gov.cn/ztzl/fjjffpzxrx/spjq/202303/t20230306_6126156.htm>(省級公安機関ページ)
- 備考: (日本対応) 振り込め詐欺被害時: ① 直ちに110番に通報し、警察からの金融機関への緊急停止(口座凍結)を求める。② 自分の取引銀行のコールセンターにも支払停止を申し入れる。③ 被害金の返還手続きは「振り込め詐欺被害者の救済に係る預金契約の取消し等に関する特別措置法」(振り込め詐欺救済法)に従って進む。送金前に疑わしければ消費者ホットライン188(消費生活センター)または警察相談専用電話#9110に相談する。

### 3. 反詐欺(振り込め詐欺)の固い規則を覚える。電話を鵜呑みにせず、情報を漏らさず、リンクを押さず、振込は何度も確認する。最も多い七つの類型詐欺がどれもこの形だ
<!-- 成本标签: 钱=0 时间=少 毅力=些 收益=大 口径=金钱 -->
- コスト: 金がかからない。「確認しないで信じない、情報を漏らさない、リンクを押さない、振込は何度も確認する」を暗記し、下の七類型を一度読み、消費者ホットライン188と警察のサイバー犯罪相談ページをブックマークし、金融機関・警察からの電話には必ず出る。振込をしろ、画面共有をしろ、知らないアプリを入れろ、リンクを押せ、認証番号を読めと言うものは、まず電話を切り、公式の電話番号にかけ直して確認する。難しいのは、相手が急かしてくる時にその急かしに耐えて先に切ることだ。
- ひとことで言うと: 振込をしろ、画面を共有しろ、知らないアプリを入れろ、リンクを押せ、認証番号を読めと言うものは、まず切って公式番号にかけ直して確認する。レビュー作業報酬、偽投資、ネットローン、コールセンター偽装、警察・検察偽装、ロマンス詐欺(杀猪盘)、性風俗誘引レビュー——この七類型はどれもあなたが先に金を送らせる。事前に見分ける方が事後に金を追うよりずっと安い。
- 効果: 法律は政府と関係部門が各種の電信網絡詐欺の手口を大衆に知らせるよう求める。(中国基準) 公安機関が金融・通信・インターネット情報部門とともに予報・防止体系を作り、詐欺に遭いそうな人を見つければ及时に止める。96110がこの全国統一予報ホットラインで、電話に出なければならない。中国公安部が2026年6月に通報したところでは、発生が最も多い10類型の詐欺が全体の電子詐欺の85%を占めた。レビュー作業報酬詐欺が発生最多で25%、偽のオンライン投資の損失が最大で全体の損失の約40%だった。福建省公安庁(中国基準)が類型別に引き裂いて示す識別特徴はこうだ。レビュー作業報酬: 「一緒に金を稼ごうという者は大抵あなたの金を稼ごうとする者」で、作業リストが終わらなければ元金を返さない。偽投資: グループチャットの「工作員」が収益を自慢し、まず少額の返金を与えて投入を増やさせた後、出金に「税金」を要求する。ネットローン: 「ローンに保証金や銀行取引明細を出す必要はない。出会ったら必ず偽物だ」。コールセンター偽装: 会員が自動決済され信用情報に影響すると言って振込を強要する。この類型の詐欺師はしばしば「会議アプリ」を入れさせた後、画面共有をオンにさせる。共有後は携帯の「メッセージポップアップ、SMS認証番号、パスワード入力がすべて見える」。上海市反詐欺センター(中国基準)の案内: 「『会議番号』『画面共有』『遠隔操作』に言及するものはすべて詐欺だ」。警察・検察・裁判所偽装: 「公検法機関にいわゆる『安全口座』はない。電話、QQ、WeChat、ネットワークで事件を処理し調書を取る『公検法機関』はすべて詐欺だ」。海外では詐欺師が在外公館を偽り、資金洗浄容疑、重要書類受領、パスポート・ビザ問題を持ち出して電話を国内の「警察」につなぐ。在中国米国大使館(中国基準)が留学生に特に念を押した。「在外公館、通信会社、税関職員を偽り違法犯罪容疑を口実に電話を公安機関につなぐものはすべて詐欺だ」。ロマンス詐欺: 「一度も会ったことがなく写真や動画しか見たことのない『恋人』をそのまま信じるな」。ビデオ通話もせず会いもしないのに、しょっちゅう切用な用事で金を要求する。性風俗誘引レビュー: 会う前に「課題」をさせ、金はますます支払わせる。事前に見分ける方が事後の支払停止より安い。支払停止でどれだけ回収できるかは、通報した時点で金がまだ口座にあるかにかかる。支払停止の方法は第2条(110番または188に支払停止を求める)を見る(中国基準、2022年12月から)。
- 根拠等級: B

### 4. 動画で顔が見え、電話で声が聞こえても検証ではない。振込が絡んだらまず切り、自分の連絡先の古い番号にかけ直して確認する
<!-- 成本标签: 钱=0 时间=少 毅力=些 收益=大 口径=金钱 -->
- コスト: 金がかからない。電話をもう一本かけ、数分余計に待つ。普段から公開アカウントに正面動画と長い音声を上げすぎない。難しいのは、相手がしばしば急かす中で、その場で振込せず踏みとどまることだ。
- ひとことで言うと: 顔が見え声が聞こえても検証ではない。振込が絡んだらまず切り、自分の連絡先に保存された古い番号にかけ直すか、お互いに知る人に一言聞く。相手が「電波が悪い」「会議中だ」と対面動画を拒否すれば、即詐欺として処理する。
- 効果: (中国基準) 公安部サイバーセキュリティ局が三つの方法を示した。第一に動作検証: 相手に連続で頭を回させたり、手のひらで顔を完全に隠して素早く退けさせたりする。原文は「現在のAI技術はこのような複雑な顔の隠蔽と光の変化を模倣する時、カクつき、ぼやけ、歪みが出やすい」と書く。第二に声の細部を聞く: 「AIが作った音声は、時に自然な呼吸の停止や感情の上下がなく、わずかな機械感、背景雑音の異常がある」。第三に多重経路検証だ。原文はこれが「最も核心的な一手」だと書く。「電話を切った後、すぐ相手がよく使いあなたが慣れている番号にかけろ(疑わしい着信番号にかけ直すな)。または二人とも知る第三者に横で確認させろ」。標語は「動画音声を軽信せず、動作検証で何度も確認せよ」だ。法律上、顔の入れ替えと音声合成はすでに詐欺用途で禁止された。顔生成、顔入れ替え、合成音声、模倣音声サービスには、プラットフォームが明確な識別標識(ウォーターマーク)を付けなければならない。いかなる組織や個人もこの標識を悪意をもって消したり、変えたり、偽造したり、隠したりしてはならない。ただし規則を守るのはプラットフォームであって詐欺師ではないので、「AI標識が見えない」を逆に相手が本物の人間である証拠として使ってはならない。中国公安部刑事偵査局(中国基準)が一件の事件を公開した。14人の集団が合成動画の顔映像5万件超、公民個人情報50万件超を作っていたことが発覚した。警察はクラウドサーバー60台を押収した(中国基準、標識義務は2025-09-01から)。
- 根拠等級: B

### 11. 避けられない侵害には反撃できる。ただし今まさに手を出している人だけを殴り、相手が止めれば止める

- ひとことで言うと: 相手が今まさに自分または他人を侵害している最中に手を出して防ぎ、相手を負傷させても明らかに過ぎなければ刑事責任はない。相手が今まさに凶器で襲いかかり、殺人・強盗・強姦・誘拐している最中なら、負傷させても殺しても過当(過剰防衛)ではない。ただし今手を出している人だけを殴り、相手が止めれば止める。最後に自分の側と認められても、先に立件され数日拘束され得る。

- ひとことで言うと: この種の考えは浮かんだ時から実行までの窓が短い。自殺未遂者82名のうち47.6%が、最初の考えが浮かんだ時から実行まで10分を超えなかったと答えた。だからすべきことは「考えを整理すること」ではなく、ハンドル、ナイフ、ガス栓、縄を自分から一歩離し、この10分を超えることだ。それからいのちの電話(0570-783-556)にかける。

### 15. 隣にいる人が「誰も幸せにさせない」「子どもも連れて行く」と言ったら、たわ言として扱わない。近親者が直接受診に連れて行け、警察も通報を受ければ必ず対応しなければならない
<!-- 成本标签: 钱=少 时间=中 毅力=些 收益=大 口径=自由 -->
- コスト: 受診の初診料は数千円から数万円だ。病院に同行すれば半日から一日かかる。難しいのは、その人を説得して一緒に行かせることだ。
- ひとことで言うと: 家族が「誰も幸せにさせない」「子どもも連れて行く」と言えば、近親者が病院に連れて行け、病院は診断を拒否できない。重症精神障害の確定診断で、すでに危害を加えているか、加えるおそれがある場合は本人の同意なしに入院治療できる。たわ言か本物か分からなければ、まずいのちの電話や保健所・こころの相談窓口に尋ねるか、110番を通報して警察を現場に来させる。隠すことは助けにならない。
- 効果: (中国基準) 精神衛生法第28条第2項:「精神障害が疑われる者が自分を傷つけたり他人の安全を害する行為をしたり、そのおそれがある時、その近親者、所属単位、現地公安機関は直ちに措置を講じて制止し、医療機関に送って精神障害の診断を受けさせなければならない」。同じ条は「医療機関は診断を受けに来た精神障害疑い患者の診断を拒んではならない」とも規定する。第29条は、病院がこのように送られてきた人を留め置き、直ちに精神科医を指定して診断し、及时に結論を出すよう求める。第30条は入院治療を本人の意思を原則とする。ただし例外が一つある。診断の結果が重症精神障害患者で、「すでに他人の安全を害する行為をしたか、他人の安全を害するおそれがある」場合は入院治療を実施しなければならず、本人の同意を前提としない。凶器乱闘を予告すること自体で、直ちに110番(中国基準 — 日本は110番)に通報できる。脅迫状を書いたり、他の方法で他人の人身安全を脅かせば、拘留5日以下または1,000元以下の過料だ。放火・爆発・危険物投入を予告して公共の秩序を乱せば、拘留5~10日と1,000元以下の過料となり得る(中国基準、治安管理処罰法は2026-01-01から施行)。
